# BDLMiner V2 2.5.7

Public statistics and optional personal monitoring now send directly to the
BDL server at `https://api.bdl-pool.com:36018`, replacing the Cloudflare Worker
address embedded in older firmware.

- Anonymous hashrate reports and the opt-in personal reports keep their existing
  five-minute schedule and data formats. Saved sharing preferences still apply.
- HTTPS uses the API hostname for certificate verification and the relay's
  explicit port, 36018, for the connection. Neither report path falls back to
  unverified TLS.
- The remote-dashboard link opens `miner.bdl-pool.com/remote.html`. The public
  website and its private viewer read the same server directly.

## Updating

Use the miner's signed GitHub updater, or upload its matching
`<board>-firmware.bin` from this release through its local dashboard. Existing
settings are retained. A factory image is for USB installation and should not
be uploaded as an OTA update.

This update removes the statistics Worker's request allowance from firmware
reporting. Server capacity and relay availability still apply. Older firmware
continues through the compatibility Worker until updated. The public chart
history was imported; personal history on the new server starts with the
reports received there.

## Validation

Host regressions cover verified HTTPS on port 443 and explicit port 36018,
report scheduling, opt-in settings and the isolation of personal readings.
Browser checks cover public statistics, remote monitoring and the updated
dashboard link. The release pipeline builds all 12 board profiles, checks image
versions and hashes, and signs the firmware centrally before publication.
