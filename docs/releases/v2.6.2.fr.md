# BDLMiner V2 2.6.2

Correction de l'affichage de la CYD à deux ports USB. Sur cette carte, qui
embarque un écran ST7789 au lieu de l'ILI9341, l'image s'affichait en portrait,
décalée et brouillée (issue [#56](https://github.com/bdlglua/BDLMinerV2/issues/56)).
Elle est désormais affichée en paysage, dans le bon sens.

## Ce qui change pour vous

- **La CYD à deux ports USB affiche correctement l'image.** Le firmware
  reconnaissait déjà son ST7789 au démarrage et inversait ses couleurs. La
  séquence de démarrage écrite pour l'ILI9341 réglait aussi un registre que le
  ST7789 interprète autrement : il retournait l'orientation de l'écran. Le
  firmware corrige désormais ce registre dès que le ST7789 est reconnu, et
  conserve l'ordre des couleurs.
- **Le journal de démarrage affiche l'identifiant de l'écran.** La ligne
  `display ID 858552` correspond à un ST7789. Si votre CYD affiche encore une
  image incorrecte, ouvrez une issue en y joignant cette ligne.
- **Les autres cartes ne sont pas concernées.** La CYD avec l'ILI9341 et tous
  les autres écrans sont pilotés exactement comme avant.

Le même changement est fait dans le code source du firmware Rust ; il sera
livré avec sa prochaine bêta.

## Mise à jour et validation

Utiliser la mise à jour GitHub signée ou le fichier correspondant
`<board>-firmware.bin` depuis le tableau de bord local. Les images factory
sont destinées à l'installation USB. Les réglages existants sont conservés.

Le workflow de publication exécute les tests natifs et d'interface, compile
tous les profils de cartes, valide les images et signe les firmwares de manière
centralisée. Ce changement n'a pas été testé sur un mineur physique.
