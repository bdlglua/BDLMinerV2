# BDLMiner V2 2.5.5

Faster completion polling for hardware SHA-256 on ESP32-S2, ESP32-S3 and
ESP32-C3. Mining results and the user interface are unchanged from
[2.5.4](v2.5.4.md).

- **Poll the digest instead of the busy flag.** While the SHA engine is working,
  its most-significant digest word reads as zero. The miner now polls that word
  and uses its nonzero value as both the completion signal and the value for the
  target comparison, avoiding a separate busy-flag wait and digest read.
- **Keep the zero-word case safe.** A completed digest can itself have a zero
  most-significant word, so the miner periodically checks the engine's busy
  state and accepts the completed zero value when appropriate.
- The change applies to the resumable SHA engine used by ESP32-S2, ESP32-S3 and
  ESP32-C3. The classic ESP32 SHA assembly path is unchanged.

## Validation

The `esp32s2-headless`, `esp32s3-headless` and `esp32c3-headless` firmware
environments build successfully. This confirms compilation for those SoC
families; it is not a physical-device performance measurement.
