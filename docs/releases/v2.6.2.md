# BDLMiner V2 2.6.2

Fix the display of the CYD with two USB ports. On this board, which carries an
ST7789 screen instead of the ILI9341, the picture came out turned into portrait,
offset and scrambled (issue [#56](https://github.com/bdlglua/BDLMinerV2/issues/56)).
It is now drawn in landscape, the right way up.

## What changes for you

- **The CYD with two USB ports shows the picture correctly.** The firmware
  already recognised its ST7789 at boot and inverted its colours. The start-up
  sequence written for the ILI9341 also set a register that the ST7789 reads
  differently: it turned the screen's orientation over. The firmware now corrects
  that register once the ST7789 is recognised, and keeps the colour order as it was.
- **The boot log shows the panel ID.** The line `display ID 858552` is an ST7789.
  If your CYD still shows a wrong picture, open an issue with that line.
- **Other boards are not affected.** The CYD with the ILI9341 and every other
  screen are driven exactly as before.

The same change is made in the source of the Rust firmware; it will ship with its
next beta.

## Updating and validation

Use the signed GitHub updater or the matching `<board>-firmware.bin` through
the local dashboard. Factory images are for USB installation. Existing
settings are kept.

The release workflow runs the native and browser suites, builds every board
profile, validates the images and signs the firmware centrally. This change has
not been tested on a physical miner.
