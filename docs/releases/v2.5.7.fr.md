# BDLMiner V2 2.5.7

Les statistiques publiques et le suivi personnel facultatif sont envoyés
directement au serveur BDL, à l'adresse `https://api.bdl-pool.com:36018`, à la
place du Worker Cloudflare utilisé par les anciens firmwares.

- Les envois conservent leur rythme de cinq minutes et leur format. Les choix
  enregistrés pour le partage et le suivi personnel restent appliqués.
- HTTPS vérifie le certificat avec le nom de l'API et se connecte au port
  explicite du relais, 36018. Les envois gardent la vérification TLS.
- Le lien du tableau de bord distant ouvre
  `miner.bdl-pool.com/remote.html`. Le site public et le suivi personnel lisent
  directement les données du même serveur.

## Mise à jour

Utilisez la mise à jour GitHub signée du miner, ou envoyez le fichier
`<carte>-firmware.bin` correspondant à votre carte depuis son tableau de bord
local. Les réglages sont conservés. Une image « factory » sert à l'installation
USB et ne doit pas être envoyée comme mise à jour OTA.

Cette version retire le quota du Worker Cloudflare pour l'envoi des
statistiques. La capacité du serveur et la disponibilité du relais restent
applicables. Les anciens firmwares passent par le Worker de compatibilité
jusqu'à leur mise à jour. L'historique des graphiques publics a été importé ;
l'historique personnel du nouveau serveur commence avec les relevés qui y sont
reçus.

## Validation

Les tests hôte couvrent HTTPS vérifié sur le port 443 et sur le port 36018,
le rythme d'envoi, les options de suivi et l'isolation des relevés personnels.
Les tests navigateur couvrent les statistiques, le suivi distant et son lien
dans le tableau de bord. Le workflow compile les 12 profils de cartes,
contrôle les versions et les empreintes des images, puis signe les firmwares
avant leur publication.
