# BDLMiner V2 2.6.3

## Statistiques publiques : migration Supabase

- Les rapports anonymes de hashrate sont maintenant transmis au collecteur de statistiques publiques BDLMiner hébergé sur Supabase, en HTTPS vérifié.
- Le site https://miner.bdl-pool.com/stats.html utilise le même collecteur. Sa mise à jour a été déployée séparément avant cette version du firmware.
- Le rapport reste limité à la version du firmware, la carte, le hashrate, l'intervalle d'envoi, la cryptomonnaie et, éventuellement, le groupe de pool publique et le modèle. Ni adresse de paiement, ni worker, ni nom d'hôte privé ne sont envoyés.
- Le collecteur conserve des échantillons historiques toutes les cinq minutes. Le nombre de mineurs est une estimation : les rapports anonymes ne prouvent pas le travail effectué.

## Mise à jour

Utiliser la mise à jour GitHub signée ou le fichier `<board>-firmware.bin` correspondant via le tableau de bord local pour conserver les réglages et les statistiques. Le fichier `<board>-factory.bin` sert à une première installation USB et peut effacer la configuration.

## Validation et limites connues

- Le collecteur Supabase a répondu HTTP 200 pour ses routes de contrôle et de lecture, et HTTP 204 à un rapport valide. Au moins un véritable M5StickC Plus2 a transmis des données.
- La CI a validé les changements d'URL Supabase dans la PR de test. Le workflow final de publication doit encore valider les images, les signatures et le déploiement.
- Lors de l'essai réel initial, le M5StickC Plus2 a transmis environ 480-505 kH/s, alors qu'il affichait auparavant environ 1 MH/s. **La cause n'est pas établie.** Vérifier `/api/stats` : `power_percent`, `limitation_reason`, `throttle`, `temp_c` et `engines`. Cette version ne prétend pas corriger ou améliorer le hashrate.
- Les anciens firmwares utilisant encore `api.bdl-pool.com:36018/report` nécessitent une passerelle de compatibilité ou une mise à jour pour apparaître dans Supabase.
- La supervision distante privée, les pools de minage et les paramètres de portefeuille restent inchangés.
