# BDLMiner V2 2.6.1

Reconnaissance de 16 pools publiques supplémentaires dans les statistiques
anonymes. Un mineur utilisant l'une de ces pools transmet désormais son groupe
public au lieu de **Autre / pool privée**, lorsque le partage anonyme du
hashrate et de la pool est activé :

- BDL Pool, SoloPool.org, KanoPool et AtlasPool ;
- Solomining.de, Satoshi Radio, Noderunners et D-Central ;
- Mining-Dutch, Luxor, NiceHash et SECPOOL ;
- SpiderPool, HMPool, Molepool et Peermining.

La page des statistiques affiche les noms et les liens officiels correspondants.
Le collecteur a été mis à jour en premier et son API en production accepte
les 16 groupes. Les choix de partage déjà enregistrés sont conservés. Le nom
d'hôte configuré, le port, l'adresse de paiement et le worker ne sont jamais
ajoutés au rapport anonyme.

## Mise à jour et validation

Utiliser la mise à jour GitHub signée ou le fichier correspondant
`<board>-firmware.bin` depuis le tableau de bord local. Les images factory
sont destinées à l'installation USB. Les réglages existants sont conservés.

Les tests de partage du firmware couvrent les 16 groupes, les sous-domaines
publics ainsi que les noms ressemblants et les hôtes privés. Le collecteur
déployé a été vérifié avec des relevés de test privés et isolés, effacés ensuite,
sans ajouter de faux mineurs aux statistiques publiques. Le workflow de
publication exécute les tests natifs et d'interface, compile les 12 profils de
cartes, valide les images et signe les firmwares de manière centralisée.
Ce changement n'a pas été testé sur un mineur physique.
