# BDLMiner V2 2.5.9

Correct the Bitaxe Gamma 601 fault diagnosis when the voltage regulator has
already shut down its output.

- A latched regulator output-overcurrent fault (`IOUT_OC`) now reports
  `Regulator output overcurrent; restart required`. Previously, the resulting
  near-zero core voltage could mask it behind `ASIC voltage fault`.
- Regulator fault status is checked before the core-voltage window. A low core
  voltage without a regulator fault still reports the ASIC voltage fault.
  Raw regulator status and measured values remain in the saved fault record.
- The dashboard translates overcurrent, regulator and ASIC-voltage faults into
  French.

This changes fault attribution, not electrical or cooling settings. Frequency,
voltage, fan control, fault thresholds, power shutdown and operator restart
requirements remain in force. The update does not repair or bypass the cause
of a regulator overcurrent or overheating event. Existing settings are retained.

## Updating and validation

Use the signed GitHub updater or the matching `bitaxe-gamma-601-firmware.bin`
through the local dashboard. Factory images are for USB installation. Other
board profiles are included as usual.

Native regressions reproduce regulator status `0x4851` with core voltage
0.027 V and verify the diagnosis, reset, power shutdown, full fan and saved
fault. The native suite, 122 browser regressions and local Gamma cross-build
pass. The release pipeline tests, builds all 12 board profiles, validates images
and signs the firmware centrally. This release makes no new physical cooling
or electrical stability claim.
