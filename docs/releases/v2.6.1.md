# BDLMiner V2 2.6.1

Recognise 16 more public pools in the anonymous statistics. A miner using one
of these pools now reports its fixed public group instead of **Other / private
pool**, when anonymous hashrate and pool sharing are enabled:

- BDL Pool, SoloPool.org, KanoPool and AtlasPool;
- Solomining.de, Satoshi Radio, Noderunners and D-Central;
- Mining-Dutch, Luxor, NiceHash and SECPOOL;
- SpiderPool, HMPool, Molepool and Peermining.

The statistics page provides the matching names and official links. The
collector was updated first and its deployed API has accepted all 16 groups.
Existing saved sharing choices are retained. The configured pool hostname,
port, payout address and worker are never added to the anonymous report.

## Updating and validation

Use the signed GitHub updater or the matching `<board>-firmware.bin` through
the local dashboard. Factory images are for USB installation. Existing
settings are kept.

The firmware's sharing regressions cover all 16 groups, public subdomains and
lookalike/private hosts. The deployed collector was checked with isolated
private test readings, which were erased afterward, without adding simulated
miners to the public statistics. The release workflow runs the native and
browser suites, builds all 12 board profiles, validates the images and signs
the firmware centrally. This change has not been tested on a physical miner.
