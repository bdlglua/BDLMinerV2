# BDLMiner V2 2.5.6

Finalisation de l’attente par lecture du hash SHA-256 matériel sur ESP32-S2,
ESP32-S3 et ESP32-C3. Les résultats du minage et l’interface restent inchangés
depuis la [2.5.5](v2.5.5.fr.md).

- **Le mot du hash signale la fin du calcul.** Les boucles de minage SHA
  reprenables interrogent maintenant le mot 7 du hash au lieu d’attendre
  uniquement le drapeau d’activité du moteur. Dès que ce mot est non nul, sa
  valeur est réutilisée pour la comparaison avec la cible, sans lecture
  supplémentaire.
- **Le cas d’un mot final nul est géré.** Le mot de poids fort peut valoir zéro
  dans un hash terminé. Le polling vérifie périodiquement l’état du moteur pour
  reconnaître ce résultat valide sans attente infinie.
- Le changement concerne le moteur SHA reprenable des ESP32-S2, ESP32-S3 et
  ESP32-C3. Le chemin assembleur SHA de l’ESP32 classique reste inchangé.

## Validation

Toute la suite de tests hôte passe, y compris les vérifications exactes du hash
et de la cible pour les noyaux SHA reprenables et le noyau pipeline de
l’ESP32-S3. Le workflow de release compile et valide les images firmware de
tous les environnements de publication avant de créer le brouillon signé.
