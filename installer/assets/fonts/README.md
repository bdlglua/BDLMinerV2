# Locally served interface fonts

IBM Plex Sans (400, 500, 600) and IBM Plex Mono (400, 500) are distributed under
the SIL Open Font License 1.1. The original notices and licenses are included in
`OFL-IBM-Plex-sans.txt` and `OFL-IBM-Plex-mono.txt`.

Sources: https://github.com/google/fonts/tree/main/ofl/ibmplexsans and
https://github.com/google/fonts/tree/main/ofl/ibmplexmono. The web fonts are
served locally; visitors do not make requests to a font provider.

The existing DM Sans font and its license are retained for earlier styles.
